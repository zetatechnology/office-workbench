## 0.1.0 (preview)

First public release.

- Viewers for Word (.docx/.docm), Excel (.xlsx/.xlsm), PowerPoint (.pptx/.pptm) and PDF files.
- Excel editing: cell input with number/date/percentage parsing, formulas, copy and paste, row/column/sheet operations, undo and redo. Saving rewrites only the changed parts of the workbook.
- CSV / TSV table editor sharing the Excel grid, with Shift_JIS / UTF-8 / UTF-16 detection.
- Word editing: paragraph text, insert, split and delete paragraphs from an edit panel next to the page view.
- PowerPoint editing: text in shapes and tables, duplicate, delete and reorder slides.
- Open Word, Excel and PowerPoint files as Markdown, and compare them with the Git HEAD version as text.
- Language model tools for reading Office files and editing workbooks, documents and presentations from chat.
